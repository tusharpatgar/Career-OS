# 03 — UI/UX Design Brief

**Status:** Direction intentionally undecided until user research and product scope are clear.

## 1. Experience principles

- Make the primary user task obvious.
- Prefer clear language over clever labels.
- Show users what data is collected and why.
- Provide feedback for every meaningful action.
- Make errors actionable and preserve user work where possible.
- Design empty, loading, and failure states—not just the happy path.

## 5. Accessibility baseline

Target WCAG 2.2 AA where applicable:
- Semantic structure and landmarks.
- Keyboard navigation and visible focus.
- Accessible names and error announcements.
- Sufficient text and control contrast.
- Reduced-motion support.
- No colour-only status indicators.

## 6. Design handoff

For each primary screen, provide:
- Purpose and target user.
- Annotated wireframe or design reference.
- Component states and interactions.
- Responsive behaviour.
- Accessibility notes.
- Acceptance checklist.
